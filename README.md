# Expense-Tracker-Python
Recently built a Python-based Expense Tracker project focused on practicing core programming concepts through a simple and interactive menu-driven system.

Features
* Add and store daily expenses
* Calculate total expenses
* View category-wise expense summary
* Identify the highest expense
* Check remaining budget and spending status
* User-friendly menu-based navigation

Concepts Used
* Python functions
* Lists and dictionaries
* Conditional statements
* Loops
* User input handling
* Data management and calculations

This project helped me strengthen my understanding of problem-solving, logical thinking, and working with real-world expense management scenarios using Python.
